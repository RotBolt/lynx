# Changelog

All notable changes are recorded here. Release archives and checksums are
published from GitHub Releases.

## 0.1.0-SNAPSHOT

- Native `lynx` CLI for macOS Apple Silicon.
- Android and iOS Simulator attachment and device discovery.
- Read-only SQLite discovery, snapshots, schema, and SQL queries.
- HTTP/1.1, HTTPS MITM, HTTP/2, and WebSocket evidence capture.
- Session-scoped JSON output and bundled vendor-neutral AI-agent skill.
- Contributor and sample-app workflows documented.

This snapshot is not a promise of physical-iOS, Windows, QUIC/HTTP-3, or
continuous watch support; those areas remain marked under construction in the
README and roadmap.
