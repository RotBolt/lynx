# Support 🩺

Use this repository's issue tracker for reproducible bugs and feature requests.
Before opening an issue:

1. Run `lynx doctor --json` and `lynx devices --json`.
2. Record the host OS, Lynx version, target serial/UDID, package or bundle ID,
   command, and complete JSON error response.
3. Redact tokens, cookies, authorization headers, personal data, and database
   contents before posting logs or captures.
4. Confirm whether the request used HTTP/1.1, HTTP/2, WebSocket, pinning, or a
   direct/native transport.

For usage questions, include the exact command and the expected versus observed
result. For release-installation problems, include the archive name and checksum
result. Do not attach private app data to a public issue.
