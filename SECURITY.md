# Security policy 🔐

Do not report security vulnerabilities in a public issue. Use GitHub's private
security advisory or vulnerability-reporting flow for this repository. If that
flow is unavailable, contact the repository maintainers through the GitHub
repository owner profile and include the smallest reproducible description.

Never include private CA keys, access tokens, cookies, authorization headers,
production database files, or unredacted network bodies in a report.

Lynx is a local debugging tool. Its capture output can contain sensitive app
data; treat snapshots and JSON output as sensitive debugging artifacts.
